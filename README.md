# OpenBreadboard
OpenBreadboard is an Electronic Design Automation software with a low entry barrier, suited for the needs of makers and hobbyists. It offers a unique real-life "breadboard" view, and a parts library with many commonly used high-level components. 

This site is meant to be a web-compliment to Fritzing
